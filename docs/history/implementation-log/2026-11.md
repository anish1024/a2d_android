### 2026-11-18 — FIX-001: Android app crash due to Room migration schema mismatch

- Status: Complete
- Files:
  - `A2D/app/src/main/java/com/a2d/app/data/local/RoomMigration.kt`
- Behavior:
  - The Room migration added `sync_id`, `updated_at`, `deleted`, `dirty` columns as nullable (default null) to the `tasks` and `action_items` tables, but the entity definitions expect these columns to be NOT NULL with default values. This caused Room's validation to fail with `IllegalStateException: Migration didn't properly handle: tasks(...)`.
  - Fixed the migration to add columns with NOT NULL and appropriate default values:
    - `ALTER TABLE tasks ADD COLUMN sync_id TEXT NOT NULL DEFAULT ''`
    - `ALTER TABLE tasks ADD COLUMN updated_at INTEGER NOT NULL DEFAULT 0`
    - `ALTER TABLE tasks ADD COLUMN deleted INTEGER NOT NULL DEFAULT 0`
    - `ALTER TABLE tasks ADD COLUMN dirty INTEGER NOT NULL DEFAULT 0`
    - Similar for `action_items`.
  - Updated the `backfillSyncIds` method to set `sync_id` to empty string and `updated_at` to `now.toLong()` (instead of using UUID or string).
  - After the fix, the app launches without crash (verified via deploy script). Unit tests still pass (except for the ARM64 native library limitation).
- Build: `./gradlew assembleDebug` → BUILD SUCCESSFUL.
- Tests: `./gradlew test` → 11 pass, 2 fail (RoomMigrationTest still fails on host due to missing native library).

## 2026-11-19 — FEAT-0002: Cloud sync (full implementation)

- **Status:** Complete
- **Files:** All sync-related files (SyncEngine, SyncDao, SyncStateEntity, TaskEntity/ActionItemEntity, TaskViewModel, MainActivity, AppModule, build.gradle.kts, CHANGELOG.md)
- **Behavior:**
  - Network stack: Retrofit 2.11 + OkHttp 4.12 + Gson (`A2DSyncApi`, `ApiClient`, `ApiModels`); `INTERNET` permission; base URL from `BuildConfig.A2D_CLOUD_BASE_URL`.
  - `TokenStore` (EncryptedSharedPreferences via `MasterKey` AES256_GCM) stores access/refresh tokens, expiry, user id, and a per-install device id.
  - `SyncEngine` (Hilt singleton) orchestrates backup-then-download: uploads dirty rows (`POST /v1/sync/backup` with `Idempotency-Key`), then downloads server changes (`GET /v1/sync/updates` keyset pagination, up to `MAX_BATCH_ROWS = 500`), marking uploaded rows clean and advancing the `sync_state` watermarks only on success.
  - `SyncDao` (Room) with dirty-row reads, watermark persistence, per-row dirty/sync-meta bookkeeping, syncId lookups, and download upserts; `SyncStateEntity` (`sync_state` table) tracks `last_backup_at` / `last_download_at` (opaque server cursor) / `last_sync_at` / `last_sync_status`.
  - Room v3: `A2DDatabase` version 2 → 3 with `MIGRATION_2_3` creating + seeding `sync_state`.
  - Domain models `Task` / `ActionItem` carry `syncId` / `updatedAt` / `dirty` (and `taskSyncId` on action items); `TaskRepositoryImpl` writes UUID `syncId` + `updatedAt` + `dirty = 1` on every save.
  - Deletions are tombstones: `TaskDao.tombstoneTask`/`tombstoneActionItemsForTask` set `deleted = 1, dirty = 1` instead of hard DELETE; display queries filter `deleted = 0`; tombstones propagate to the server on the next backup.
  - `TaskViewModel.syncNow()` is a suspend function wired to the injected `SyncEngine`; `MainActivity` runs it in a coroutine scope and surfaces the result via Toast ("Cloud sync OK: uploaded N, downloaded M" / "Cloud sync failed: ...").
  - DI: `AppModule` provides `A2DDatabase`, `TaskDao`, `SyncDao`, `ApiClient`, `TokenStore`, `SyncEngine`.
  - Dependencies added in `libs.versions.toml` + `app/build.gradle.kts`: retrofit 2.11.0, converter-gson 2.11.0, okhttp 4.12.0, logging-interceptor 4.12.0, security-crypto 1.1.0-alpha06, work-runtime-ktx 2.9.0.
- **Build:** `./gradlew assembleDebug` → BUILD SUCCESSFUL (42 tasks).
- **Tests:** `./gradlew testDebugUnitTest` → 13 tests, 2 pre-existing Robolectric native-library failures (ARM64 host limitation, unchanged); all domain/logic tests pass.
